# Decryptor

Расшифровщик прошивки RP2040, которая отдаётся хостом по USB Mass Storage.
Восстановлен реверс-инжинирингом по дампу full_flash.bin

## Что делает

Читает дамп памяти, расшифровывает зашифрованную область и сохраняет
результат в отдельный файл.

## Алгоритм решения

Прошивка читается хостом через USB MSC секторами по 512 байт. В дампе
нашёлся колбэк чтения и характерные константы PRNG; в частности
0x41C64E6D, шаг LCG из MSVC rand(). Дальше - реверс:

- сид считается от номера LBA линейно;
- внутри сектора кейстрим крутится LCG-ом, шаг 0x41C64E6D;
- каждый 16-байтный блок XOR-ится с четырьмя 32-битными масками;
- маска собирается из старших байт v10 +- const со сдвигами 0/8/16/24.

Проверка: после расшифровки первые байты дампа — EB 3C 90, начало
boot-сектора. Структура данных корректная, значит алгоритм верный.

## Формула

    v10 = (0x38C9CDA0 * lba - 0x61C85616) mod 2^32

    for blk in 0..31:              # 32 блока по 16 байт = 512 байт
        for d in 0..3:             # 4 dword'а в блоке
            dword[blk][d] ^= mask(v10, d)
        v10 = (v10 + 0x41C64E6D) mod 2^32

Маска для dword d - это 4 байта, каждый из которых равен
HIBYTE(v10 +- const), поставленному в свою позицию. Все 16 констант
и сдвиги лежат в MASKS в коде.

## Использование

    decryptor <input.bin> <output.bin>

На вход - дамп. На выход - расшифрованные байты.

## Сборка

rustc -O decryptor.rs -o decryptor

## Запуск

./decryptor full_flash.bin rsdecrypted.bin

## Дополнительно

- Смещение зашифрованной области в файле: 0x100000 (1 МиБ).
  В памяти она лежит по адресу 0x10100000, база дампа — 0x10000000.
- Размер зашифрованной области: 2048 LBA * 512 байт = 1 МиБ.
