# Атака по побочным каналам

## Описание

С помощью полученной функции проверки пароля было замечено, что при подаче корректного пароля против некорректного плата тратит большее время на проверку пароля
Каждая угаданная цифра уведичивает время сигнала на 50 мс. Для проверки померяли время осциллографом, щупы - один к земле, второй к 10-ке.
